# LightPollution

- Начинайте с [README](README.md). Открывайте нужный раздел теории, модели
  или ограничений, если задача затрагивает этот раздел.
- Проверяйте физические расчёты и единицы на совместимых данных. Для
  наблюдений указывайте прибор, время, географию, происхождение входов и QA.
- Фиксируйте решения в тематическом документе. [HISTORY](HISTORY.md) хранит
  этапы проекта, [CODE_CHANGELOG](docs/CODE_CHANGELOG.md) — правки кода,
  тестов и скриптов с проверками, статусом и временем Europe/Berlin.
  Воспроизводимые результаты складывайте в [artifacts](artifacts/README.md).
- Для кода запускайте `uv run pytest -q -p no:cacheprovider` и
  `uv lock --check`. Тесты работают офлайн. Секреты, рабочие базы и
  временные скачивания храните вне Git.
- Завершённые изменения коммитьте и отправляйте в `main`. Сохраняйте
  опубликованную историю.
