# Аудит источников для бенчмарка
> Дата создания: 2026-11-13

Я сохраняю поиск и ограниченную проверку публичных данных.
Основной документ — [BENCHMARK](../../BENCHMARK.md). Папка названа
по началу аудита; оформление продолжилось после полуночи Europe/Berlin.
В каждом запросе записано фактическое время UTC.

## Что проверено

- 42 семейства источников, 12 групп кандидатов: свет/спектры/диаграммы,
  атмосфера/профили, поверхность/снег/рельеф, Луна/сумерки, звёзды,
  глаз, камера и численные референсы.
- 129 URL-проверок:110 HTTP200,14 HTTP404,4 HTTP403,1 тайм-аут.
  Включены ошибочные и исправленные пути/версии. Это число адресных
  проверок, а не число пригодных баз или сцен.
- Прочитано30462094 байта; крупные архивы проверялись префиксами.
  HTTP200 не признан доказательством численной пригодности.
- Новых расчётов LightPollution/подгонок/изображений/benchmark-оценок:0.
  Полностью квалифицированных новых случаев:0. JPL endpoint опрошен
  для проверки доступа; внешние модели переноса не запускались.

Запросы сделаны без ключей и учётных данных. Страницы из веб-поиска
дополнительно цитируются в BENCHMARK; не все литературные источники
являются загрузками численных данных в этом журнале.

## Что потребовало исправления при проверке

1. CMR для VNP46 требует version=2, MCD43/MCD15 —061. Пустые ответы
   с другими строками версии не доказывали отсутствия исторических данных.
2. Пересечение CMR включало предыдущий месячный композит и 16-дневные
   окна MODIS. Для альбедо отдельно найден точный центр/тайл.
3. Старый NOAA ISD-lite URL отдал HTML. Вместо него получен полный
   Global Hourly CSV из публичного NOAA S3.
4. ACTRIS Swagger найден по действующему пути. Продукт71720 относится
   к Barcelona; Granada отдельно проверена по75096. Эти профили не
   выданы за мадридские измерения.
5. Из числа временных столбцов спектров исключена завершающая пустая
   ячейка. Gaia VOTable имеет бинарную сериализацию: отсутствие TR-тегов
   не означает пустой спектр; настоящий разбор получил343 строки.
6. Скаляры NetCDF и fill-маски обработаны при извлечении чисел.
   Из промежуточного аудита удалены сырые длинные строки/JavaScript;
   в Git остались только метаданные и хеши, без переиздания массивов.

## Воспроизводимость и права

Для повторного чтения используются requested_url и ID продукта.
Мутируемый каталог может измениться; хешируется ответ с указанным UTC.
Хеш prefix не подтверждает весь архив. Рабочие ответы лежат в
игнорируемой scratch-папке; выводы/URL/счётчики отслеживаются Git.

Прежние Earthdata-секреты не использованы. Подписанные провайдерами
query-параметры не сохранены. У LSPDD/камер/статей разные лицензии;
публичная ссылка не означает разрешения включить оригинал в дистрибутив.
Нужные регистрации и неподтверждённые права указаны в BENCHMARK.
Сообщения авторам не отправлялись.
