LightPollution как дополнения KStars с приближённым видом невооружённым
глазом и более обоснованным прогнозом съёмки. Обновлены описание, теория,
данные для дальнейшей работы и порядок проверки результатов.

## Основные выводы

INDI CCD Simulator уже имеет Sky Glow. Ekos Exposure Calculator использует
фон, шум считывания, QE и размер пикселя. В исследованных функциях не найден
географический атмосферный расчёт неоднородной засветки; синтетический кадр
использует условную шкалу ADU и упрощённый шум. Вывод получен чтением кода,
а не испытанием новой сборки.

Отдельная модель глаза необходима: порог обнаружения, яркость восприятия,
цвет и экранное отображение — разные задачи. Общая абсолютная/спектральная
калибровка нужна обеим ветвям. Одной карты VIIRS и произвольного JPEG
для этого недостаточно.

## Статус проверки

Изменения касаются документации и отчётных материалов. Новых моделей,
прогонов в точках, исходных измерений и полевой валидации в этом этапе нет.
Автотесты не запускались: код и тесты не изменялись. Проверяются ссылки,
формат, соответствие манифеста скачанным источникам и читаемость PDF.
Завершение проверок фиксируется в `verification.json`.

Полные чужие PDF и файлы исходников находятся во временном исключённом из
Git каталоге и здесь не распространяются. Изображения прежних опытов не
изменялись. Формат следующих отчётов закреплён в конце плана.
