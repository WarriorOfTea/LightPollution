# Проверка рассеяния и читаемой математической записи
> Дата создания: 2026-11-12

Я проверил фактический путь NASA → источники → атмосфера → наблюдатель,
уточнил описания приближений и перевёл формулы канонических THEORY/MODELS
в LaTeX. Нового решения Ми, многократного переноса или кругового интерфейса
этот этап не добавляет. Формальная теория остаётся в корневых документах;
здесь сохраняю только условия опыта и проверки редакции.

## Контролируемая чувствительность

Числа: [sensitivity.json](sensitivity.json). Воспроизведение из корня:

```bash
uv run python scripts/audit_scattering.py
```

Один источник с единичной условной мощностью вверх, ламбертовская диаграмма,
40 км по меридиану южнее наблюдателя. Наблюдатель:60°N,30°E,20м над сферой.
Азимут180°, высоты10/45/90°, длина волны550нм. Нет NASA-данных, DSM, снега,
фоновых слагаемых и переоценки масштаба. Меняю только AOD или g при остальных
исходных параметрах Atmosphere. Поэтому результат объясняет чувствительность
ядра, но не измеряет погоду или ошибку реального неба.

Для каждого из6 сценариев считаю3 направления при192 внешних сегментах/
24 внутренних узлах и повторяю при384/48. Это18 сравнений с уточнением,
без независимых полевых измерений. Изменение квадратуры не исправляет
физическую ошибку отсутствующих порядков. Полные значения и хеши кода
записаны в JSON; краткая таблица перенесена в MODELS.

## Документация и PDF

LaTeX-источники: [THEORY](../../THEORY.md), [MODELS](../../MODELS.md).
Для чтения можно построить общую копию:

```bash
uv run python scripts/build_theory_bundle.py --output scratch/scattering-notation/bundle
```

Она включает также LIMITS/VISUALIZATION и не является отдельным редактируемым
источником. Экспортёр отображает математическую запись через MathText в600dpi,
а не печатает код формулы моноширинным текстом. Кодовые блоки сохраняются.
Неподдержанная или незакрытая формула останавливает экспорт; это ограниченный
поднабор LaTeX, не универсальный TeX-компилятор. В исходном Markdown допустимы
обычные GitHub-формулы; в текущих документах использован совместимый поднабор.
