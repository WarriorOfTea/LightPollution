# Радиальный спад ореола в четырёх направлениях

[PDF с измеренными профилями, формулами и таблицами](spad-gorodskogo-oreola-po-storonam.pdf)

После [проверки завышения мощности](../halo-transfer-diagnosis-20261128/README.md)
я оцениваю общий масштаб по яркому ядру и испытываю угловое
перераспределение по спаду ореола. Проверил 15 пролётов над Берлином,
Мадридом и Тусоном. К десяти прежним наблюдениям Suomi NPP добавил
пять соответствующих пролётов NOAA‑20. В парах той же ночи разница
во времени 49,3–51,1 минуты, по азимуту 172,6–173,2°. Восемь замеров
Балагера сохраняю в прежнем сравнении, пригодного ореола за проверенные
даты там нет. Фотометры использую только для проверки.

## Метод

Из A1 Collection 2 беру калиброванную радиансность на верхней границе
атмосферы, с фильтрами качества, Луны и Солнца прошлого опыта. По
месячной карте нахожу яркие клетки города с NearNadir от 2 нВт/(см²·ср).
Измеряю расстояние до ближайшей такой клетки. Внешние слабо
светящиеся клетки делю на четыре сектора и радиальные интервалы
4–8, 8–13, 13–19, 19–28 и 28–40 км. За 40 км от края использую
дальний контроль. Блоки 4×4 клетки держу группами около 5–7 км и
откладываю примерно треть групп. Среднее интервала требует от трёх
блоков и двух групп. Сопоставление двух ракурсов использует общие
пригодные клетки и географию секторов Suomi NPP.

При $mu=sinalpha<1/2$ пробная диаграмма
$L=L_{H2}+kappa O(1-2mu)(1-4mu)$, за этим пределом остаётся H2.
Допустимый интервал по $Lgeq0$ равен $[-2,5+2sqrt6]$.
Полный поток $F=2pi Aintmu L,dmu$ сохраняется.
Взвешенный интеграл добавки до $mu<1/2$ равен
$	frac12mu^2(1-2mu)^2$. Это изменяет, например, долю ниже 10°
или 25° при фиксированной доле ниже 30°. Сохраняю обе угловые опоры
NearNadir/OffNadir. Масштаб $s$ и компоненты внешних источников и фона
оцениваю по ядру, ярким соседям и дальнему контролю. Таким образом
$F=sF(H2)$, а свет меняет форму при неизменном $s$.

Для ореола оцениваю $kappa$ по разностям соседних радиусов и
противоположных секторов. Это сокращает постоянный фон. Ковариация
$DCD^mathsf{T}$ учитывает общие радиальные интервалы и общие
пространственные группы. Добавляю минимум 0,02 нВт/(см²·ср) к
оценке типичного шума средних интервалов по квадратуре. Для контроля
пробую раздельный спад по кольцам, спад по четырём секторам, разность
сторон, объединённую оценку и двойную разность между спутниками.
Во всех ядрах моделирую одно и повторные рассеяния. Прогноз на
другом пролёте использует форму только из пролётов-доноров. Масштаб
и фон определяются по собственным контрольным областям целевого
пролёта.

## Что показали измерения

На 8 290 отложенных блоках средняя ошибка с калибровкой по ядру
0,0610 нВт/(см²·ср), при совместной подгонке спада и разности сторон
0,0592 нВт/(см²·ср). Для 161 отложенной разности соседних
радиусов MAE спада изменилась с 0,0089 до 0,0088 нВт/(см²·ср·км).
На другом спутнике той же ночи ошибка ореола изменилась с 0,0517
до 0,0490 на тех же 6 202 блоках. Для 73 разностей сторон этого
контроля ошибка выросла с 0,0634 до 0,0645 нВт/(см²·ср).

На 14 из 15 пролётов совместная подгонка упёрлась в предел углового
диапазона. Типичное изменение среднего интервала между двумя краями
допустимых форм 0,0073 нВт/(см²·ср) по медианам пролётов.
Сценарии высоты аэрозоля при той же AOD, например, переводят
оценку Берлина с одного края допустимого диапазона на другой.
Оценки масштаба по яркому ядру лежат между 0,82 и 1,14 от H2.
Два ракурса одной ночи Тусона расходятся в оценке масштаба
максимум на 17%. Полосы на графике — размах проверки сценариев,
выборка не поддерживает узкий доверительный интервал городской доли.

| Вариант | Наземная MAE, % | Наземное смещение, % | Замеров |
|---|---:|---:|---:|
| H2 | 28,39 | −23,18 | 72 |
| Масштаб только по ядру | 27,91 | −22,11 | 72 |
| Спад по кольцам | 27,83 | −21,17 | 72 |
| Спад по четырём сторонам | 27,97 | −21,44 | 72 |
| Разность сторон | 27,47 | −20,47 | 72 |
| Спад и разность сторон | 28,10 | −21,53 | 72 |
| Прежняя свободная подгонка | 55,94 | +35,81 | 72 |

В Тусоне на 28 точках получили 22,66% у H2, 21,82% после калибровки
по ядру и 21,81% при переносе угла с другого спутника. Последний
результат воспроизводится при заранее заданной верхней границе
формы. По дальним точкам Мадрида остаётся занижение на 53,90%
(12 замеров). В Берлине на 12 точках H2 даёт 8,88%, совместная
подгонка 10,66%. Улучшение общей ошибки ореола лишь слабо ограничивает
тонкую структуру излучения. Фиксация общего потока позволяет
проверять форму без прежнего большого завышения на земле.

Для Тусона спутники проходили при сопоставимых режимах муниципальных
фонарей внутри каждой пары, наземные отсчёты взяты до местной
полуночи. Исторические профили аэрозоля непосредственно над городами
отсутствуют. Использую дневную опору AERONET и атмосферные сценарии
прежнего опыта. Для Тусона согласую $g(650,mathrm{нм})=0,644$ с
исходной наземной постановкой. Варианты без слабых огней, с постоянным
фоном, другим ярким краем и аэрозолем дают 27,05–28,18% на тех же
72 наземных точках. Номинальный отбор задан до сравнения с землёй.
Сравнение двух приборов использует один серый DNB-прокси и сохраняет
разницу фактического спектрального отклика как ограничение.

Я запускаю расчёт профилей с временной зависимостью
`uv run --locked --with scipy==1.18.1 python scripts/run_halo_radial_profiles.py …`.
Порядок аргументов указан в `--help`. Каталог Suomi NPP, месячные карты
и границы беру из [проверки переноса](../halo-ground-validation-20261128/README.md).
Для NOAA‑20 беру отдельную папку пяти гранул по манифесту. Второй
скрипт читает их сводку и готовые [наземные отклики по порядкам](../halo-transfer-diagnosis-20261128/ground-response.json).
На каждой сцене рассчитано пять атмосферных сценариев, всего
75 ядер по 1 048 576 траекторий. Сверил повторный расчёт основного
результата, а перенос на землю сравнил с архивом H2 на каждой точке.
