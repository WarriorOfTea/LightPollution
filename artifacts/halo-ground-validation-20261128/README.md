# Перенос параметров городского ореола к наземным наблюдениям

[PDF с таблицами, графиками и прогнозами по каждой точке](proverka-gorodskogo-oreola-i-fotometrov.pdf)

Я заново рассчитал наземные прогнозы для 80 прежних замеров и проверил,
улучшают ли их параметры, подогнанные исключительно по суточным
наблюдениям VIIRS A1. Для 72 наземных точек есть пригодная оценка города,
для остальных восьми, в Балагере, я воспроизвёл исходное сравнение.
Из 23 дат спутниковых наблюдений прошли отбор 10. На 12 датах отбор
исключил измерения, за 19 февраля 2012 года в каталоге не нашёл суточные
плитки для окна Мадрида. Для его наземной ночи пригоден пролёт 20 февраля.

## Модели и контроль переноса

Я использую одинаковые месячные пространственные карты, границы городов
и аппарат QA прежнего [суточного опыта](../viirs-halo-airglow-20261127/README.md).
В A1 использую Солнце ≤−18°, Луну ≤−10°, флаги VIIRS и ±3 минуты
одного пролёта. Совместно оцениваю яркое ядро, слабый ореол 18–43 км,
дальний контроль и яркие соседние огни. В каждом классе подгонка
учитывает типичную величину сигнала и число блоков. Ореол сравниваю
на отложенных группах около 7 км, среднее по пролётам взвешено поровну.

- **H1/H2.** Постоянное продолжение OffNadir и усиление радиансности к
  горизонту. Это прежние наземные модели. Для спутникового сравнения
  соседние огни и постоянный фон оцениваю отдельно для каждой версии.
- **A1 · масштаб.** Для города оставляю форму Ламберта, оцениваю
  масштаб его исходной NearNadir-карты из A1.
- **A1 · свободная.** По A1 оцениваю два неотрицательных веса для
  единичных восходящих потоков Ламберта и пригоризонтного шаблона
  с радиансностью $\exp(-\sin\alpha/\sin10^\circ)$. Меняются диаграмма и
  суммарный поток.
- **A1 · форма.** Ту же спутниковую смесь возвращаю на исходный
  уровень NearNadir в диапазоне 0–20° от зенита. Это диагностика
  переноса формы при известном NearNadir, без подгонки по фотометрии.
- **A1 · хвост N/O.** Подгоняю только $\kappa$ в
  $L=O[1+\kappa(1-2\sin\alpha)]$ при $\alpha<30^\circ$. H1 соответствует
  $\kappa=0$, H2 — $\kappa=1$. Наклон сохраняет оба заданных спутником
  уровня. Во всех трёхмерных расчётах оставляю сумму всех порядков
  рассеяния.

На земле фиксирую исходные границы, карты огней и годовое заполнение
пропусков, исходный спектр и атмосферу, естественный фон, соседние огни,
калибровку и апертуры приборов. Спутниковый остаточный фон и коэффициент
соседних источников в наземную модель не переношу. Для тех же случайных
траекторий старые вклады совпали с архивами с допуском $3\cdot10^{-11}$
по относительному отличию и $3\cdot10^{-12}$ по абсолютному для
монохроматических коэффициентов. В каждом полном прогоне 468 спектральных
интеграций на 47 972 352 траекториях. Для спутника использовал 1 048 576
траекторий на пригодный пролёт. Новые веса не подбирал по фотометрии.

## Что изменилось

Числа — средняя абсолютная ошибка / смещение со знаком в процентах
линейной полной яркости по тем же наземным наблюдениям.

| Город | Сопоставлено / всего | H2 | A1 · масштаб | A1 · свободная | A1 · хвост N/O |
|---|---:|---:|---:|---:|---:|
| Берлин | 12/12 | 8,88 / −5,56 | 15,41 / −13,43 | 144,62 / +144,62 | 127,41 / +127,41 |
| Мадрид | 32/32 | 40,72 / −40,58 | 42,18 / −42,18 | 28,89 / −15,97 | 26,16 / −11,79 |
| Тусон | 28/28 | 22,66 / −10,86 | 21,02 / −17,69 | 67,67 / +59,70 | 59,35 / +50,94 |
| Балагер | 0/8 | 11,27 / +10,15 по прежнему опыту | — | — | — |
| Общая выборка | 72/80 | 28,39 / −23,18 | 29,49 / −27,86 | 63,26 / +40,22 | 55,94 / +35,81 |

Для 68 замеров, где использована указанная в протоколе дата пролёта
той же ночи, ошибка H2 составила 28,80%, подогнанного хвоста 54,49%.
Для четырёх замеров Тусона 29 марта использовал пролёт 31 марта из-за
высоты Луны. Остальные пролёты Тусона позже наземных замеров на 1,5–3,0
часа. У фонарей после полуночи действовали другие настройки.
На ночь Балагера 3–4 мая пригодный по Луне пролёт дал 3 пригодные
яркие ячейки ядра и 0 ячеек слабого ореола. Среди 11 проверенных дат мая
никакая не дала поддержки, необходимой для оценки параметров города.
[Таблицы режимов фонарей Тусона](https://doi.org/10.1177/1477153520958463)

На 10 пролётах и 2 118 отложенных пространственных усреднениях
MAE ореола H2 составила 0,1066 нВт/(см²·ср), свободной смеси
0,0878, подогнанного хвоста 0,0852. Улучшение на спутнике сочетается
с существенным завышением на земле. В берлинском пролёте 29 марта
калибровка потребовала $\kappa=26{,}73$ при заданном OffNadir. Для
одной ячейки добавочная восходящая мощность в этой параметризации
равна $\kappa\pi A O/12$. Это может повышать яркость дальних лучей,
а по одному ракурсу зависимость геометрии хвоста от аэрозольного профиля,
приборного ореола и остаточного фона остаётся неопределённой.
На восьми мадридских точках с преобладанием города выигрыш по модулю,
видимый в полной выборке, исчезает: MAE H2 26,53% против 27,83%
с подогнанным хвостом. Смещение меняется с −25,97% до +25,09%.

Для этих данных выбор общего усиления по A1 не улучшил наземный прогноз.
Улучшение в Мадриде относится к этим наблюдениям и данной модели переноса.
H1/H2 остаются опорными сценариями. Для определения нового хвоста нужна
согласованность нескольких ракурсов и наземных наблюдений в сопоставимом
режиме освещения.
