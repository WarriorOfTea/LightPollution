# Отчёт: единая сцена, относительная шкала и лунный фон
> Дата создания: 2026-11-10

> Я сохраняю этот отчёт как архив конкретного опыта. Его статусы относятся к описанной версии; текущее устройство — в [MODELS](../../MODELS.md), ход развития — в [HISTORY](../../HISTORY.md).

Реализованы первые три пункта последнего согласованного плана: единое описание
наблюдения, общая относительная фотометрия и однополосная лунная засветка.
Это исследовательское численное ядро; полевая точность пока не установлена.

## 1. Что сделано

**Единая сцена.** JSON версии 1 и команда `observe`. Режим `dated` принимает
дату/время с часовым поясом, место и направления; получает эфемериды Солнца,
Луны и звёзд. `undated` требует явно заданную Луну либо безлунный сценарий,
не назначает текущую дату и не придумывает положение звёзд. По умолчанию
без облаков. Неполные, несовместимые входы и сумерки отвергаются.

**Общая шкала.** Все фоновые компоненты сохраняются отдельно в `B/Bref`,
с одной V-полосой и опорой. Городское поле получает явно объявленную
привязку масштаба; опоры разных полей не складываются. Исходный 550-нм
перенос связан с V через эффективное серое приближение, не через ложное
равенство DNB, 550 нм, V и чувствительности глаза.

**Луна.** Реализованы формулы Krisciunas–Schaefer 1991, нелинейная фазовая
яркость и дополнительная обратноквадратичная поправка расстояния.
Экстинкция выводится из той же заданной атмосферы. Результат складывается
с городским/естественным фоном в линейном свете. Ближние 10° и возможные
затмения отмечаются как неподдерживаемые; остаточное рассеяние при Луне
под горизонтом и оппозиционное усиление пока отсутствуют.

Формальные определения, физические законы, вывод формул, единицы, коэффициенты,
контракт и ограничения — [OBSERVATION_MODEL.md](https://github.com/WarriorOfTea/LightPollution/blob/52a3604b6603be48e07c4bd0d60a9cf32f0b9f38/docs/OBSERVATION_MODEL.md).
Пользовательское пояснение — [путеводитель](https://github.com/WarriorOfTea/LightPollution/blob/52a3604b6603be48e07c4bd0d60a9cf32f0b9f38/docs/PHYSICS_AND_MATH_GUIDE.md).
В этом каталоге также сохранён [PDF формальной модели](https://github.com/WarriorOfTea/LightPollution/blob/52a3604b6603be48e07c4bd0d60a9cf32f0b9f38/artifacts/observation-core-20261110/observation-model.pdf).

## 2. Входы и происхождение масштаба

Во всех семи случаях повторно использовано рассчитанное ранее поле реальных
VNP46A4.002 за 2025 год для точки 60,300° N, 30,315° E, 20 м. SHA-256 поля
и исходная метаинформация входят в каждый `observation.json`. Новых HDF5
NASA не скачивалось, городской перенос не пересчитывался.

Искусственный зенит 20,5 V mag/arcsec² и однородный естественный фон
21,6 V mag/arcsec² — **сценарные входы**, не измерение яркости над Петербургом.
Общая опора `μref=22`, AOD=0,1. Четыре условных лунных случая меняют только
фазовый угол при азимуте 180°, высоте 30° и расстоянии 384400 км.
`α=0°` — полнолуние, `180°` — новолуние; α не равен освещённой доле диска.

Для дат 2025 и 2027 меняется астрономическая геометрия. Годовая карта
источников и атмосфера остаются фиксированными: это не прогноз будущего
городского освещения или погоды и не реализованная сезонная модель.

## 3. Численные результаты

Ниже фон в зените. `q` — относительно одной и той же опоры, не яркость пикселя
экрана. Меньшая поверхностная величина означает более светлое небо.

| Случай | Поддержано направлений | Звёзд экспортировано | q Луны | q всего | μ всего, V mag/arcsec² |
|---|---|---|---|---|---|
| Без Луны | 10/10 | 0 | 0.000000 | 5.426511 | 20.163698 |
| α=30° | 9/10 | 0 | 11.407106 | 16.833617 | 18.934556 |
| α=60° | 9/10 | 0 | 5.317869 | 10.744380 | 19.422047 |
| α=90° | 9/10 | 0 | 2.135503 | 7.562014 | 19.803406 |
| α=120° | 9/10 | 0 | 0.617595 | 6.044106 | 20.046670 |
| 12.01.2025 | 10/10 | 4535 | 36.956583 | 42.383094 | 17.932018 |
| 20.01.2027 | 10/10 | 4541 | 31.486391 | 36.912903 | 18.082055 |

Подписи дат указаны по UTC; точный час сохранён во входах и результатах.

Всего 66/70 направлений поддержано. 4/70 исключены намеренно: в каждом
ручном лунном случае одно направление совпадает с Луной. Там лунный и
суммарный фон — `null`, а не ноль. Это проверка ограничения, не сбой расчёта.

В датированных каталогах 4535 и 4541 звезда над геометрическим горизонтом;
величины ослаблены заданной атмосферой. Это не число звёзд, видимых глазом.
В пяти недатированных случаях экспортировано 0 звёзд, поскольку времени нет.

Полные входы: `*.scene.json`; результаты: `<case>/observation.json`,
`directions.csv`, `stars.csv`; сводка и сравнения — [results.json](results.json).

## 4. Проверки и их смысл

- **Полный pytest:** 88/88 passed, 0 failed, 0 errors, 0 skipped; 16,45 с.
  Из них 24 проверки новой функциональности, 64 прежние. [JUnit](pytest.xml).
- **Исходная таблица KS1991:** 16/16 проверенных значений укладываются в
  ±0,5 нЛ — точность опубликованного округления. Максимальная разность
  0,408864 нЛ. В таблице всего 20 значений; четыре при ρ=5° исключены
  из области реализованной версии, а не объявлены воспроизведёнными.
- **Независимый опубликованный пример specsim:** 19,854844 против
  опубликованных 19,855 V mag/arcsec²; различие 0,000156 величины.
- **Смена общей опоры 22 → 20:** отношение компонентов и итоговая величина
  сохраняются; максимальное отличие итоговой величины 3,55×10⁻¹⁵.
- Проверены закон обратных квадратов, нулевой фон при нулевой экстинкции,
  нелинейная фазовая зависимость, ручная/эфемеридная геометрия, часовой пояс,
  затмение, сумерки, несовпадение метаданных сетки и очистка устаревшего CSV.
- CSV сохраняются с фиксированным LF: контрольные суммы сохраняются после
  Git checkout. После исправления формата повторены все 88 тестов и семь случаев.
- `uv lock --check`, компиляция Python и `git diff --check`: успешно.

Это проверка формул, реализации и воспроизводимости. Она не подтверждает
процент совпадения с реальным небом. Реальных калибровочных/проверочных
ночей этим этапом не добавлено; физическая ошибка — неизвестна.

## 5. Ограничения и следующий этап

Сценарные масштаб/спектральное приближение, неизвестная местная атмосфера,
ближние источники до 3 км и источники за окном карты остаются ограничениями.
KS использует эмпирическую угловую функцию: это не полное спектральное решение
с произвольными свойствами аэрозолей. Глаз, камера и новый рендер не реализовывались.
Прежний renderer сохраняет ограничение на Луну над горизонтом.

Далее — атмосферная чувствительность и согласованный наземный случай,
затем сезонный масштаб. Это отдельные этапы 4–5, не часть заявленного результата.

## 6. Воспроизведение

Из корня репозитория:

```bash
uv run python scripts/run_observation_cases.py
uv run lightpollution observe \
  --scene artifacts/observation-core-20261110/dated-2025.scene.json \
  --output scratch/check-observation
uv run pytest -q -p no:cacheprovider
uv lock --check
```

[Манифест проверки и SHA-256](verification.json) фиксирует версии и артефакты.
[PDF этого отчёта](implementation-report.pdf) предназначен для чтения вне GitHub.
Изменения относятся к исследовательскому коду в `main`, не к production-релизу.
